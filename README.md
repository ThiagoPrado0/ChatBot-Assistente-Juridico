# ChatBot-Assistente-Juridico
Projeto desenvolvido durante curso da Data Science Academy
• Assistente conversacional para orientação jurídica básica, construído com LLM e orquestração via LangChain.
• Inclui interface web interativa em Streamlit e consumo de modelo via API da Groq.
• Tecnologias: Python, LangChain, Streamlit, Groq API, engenharia de prompt.
